# Настройка окружения (Docker)
В Dockerfile скачали минимальный образ альпины. Поставили расширения и потом из Docker hub скачали готовый бинарник
(чтобы заново не проходить установку и тд)

Далее в CMD запускаем команду php-fpm, который запсукается менеджера процессов. Создается main процесс и сокет к нему по умолчанию
на 0.0.0.0:9000

## Роль nginx
Соединение приходит на сокет (Kernel распределяет), который создал Nginx процесс. Например 80. 
Nginx умеет работать с сырми битами из соединения и формирует по протоколу FastCGI и передает это ОС (Kernel).
Ядро кладет этот FastCGI пакет в сокет 0.0.0.0:9000 и потом уже забирает его FPM

## Роль FPM
Сам по себе PHP простой язык программирования, который просто выполняет код сверху вниз и отдает ответ в виде текста.
FPM принимает от nginx соединение и превращает пакеты в, PHP понятные, метаданные.

1. [Сетевая карта] ➔ [Ядро Linux (Буфер порта 80)] ➔ (команда read) ➔ [Программа Nginx]
2. [Программа Nginx (переводит в FastCGI)] ➔ [Ядро Linux (Буфер порта 9000)] ➔ (команда read) ➔ [Программа PHP-FPM]
